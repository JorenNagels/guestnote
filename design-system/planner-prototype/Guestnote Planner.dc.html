The sheet primitive

One container, three slots. The sidebar is a sheet; so is the mobile drawer, and so is the command palette’s panel. What the sheet owns is the geometry — a fixed-height column with a header and footer that never scroll and a body that does.

slot: head

Pinned. Holds the org, and nothing else — the product’s own wordmark appears only as the quiet “powered by” line in the footer bar.

slot: body · overflow-y auto

The only scrolling region. It takes the leftover height, which is what makes the many-weddings state scroll internally instead of pushing the account menu off the screen.

slot: foot

Pinned. The account menu, and above it the collapse control.

Why the empty state has no chrome

A signed-in user with no memberships is a real reachable state, not an error — anyone who can receive mail can reach a session. The empty state says so in words rather than rendering a nav with no links.
